## Hakkımda

Elektrik-Elektronik Mühendisliği mezunuyum. ERP tabanlı sipariş, stok ve e-ticaret süreçlerinin
operasyonel yönetiminde 2 yıla yakın deneyimim var — yani analiz ettiğim süreçleri daha önce
sahada bizzat yürüttüm.

Kariyerime **iş analizi** alanında devam ediyorum. Bu profildeki vaka çalışmalarını, gereksinim
analizi ve süreç modelleme yetkinliğimi somut çıktılarla göstermek için üretiyorum: paydaş
görüşmesinden BRD'ye, user story'den UAT senaryolarına kadar uçtan uca dokümantasyon.

Şu anda bir veri bilimi bootcamp'i sürdürüyorum; SQL ve Power BI tarafını da bu doğrultuda
derinleştiriyorum.

## Odak alanlarım

| Alan | Neler yapıyorum |
|---|---|
| **Gereksinim analizi** | Paydaş ve etki analizi, gereksinim görüşmesi tasarımı, muğlak talebi ölçülebilir gereksinime dönüştürme, BRD, iş kuralı (BR) ve fonksiyonel/fonksiyonel olmayan gereksinim (FR/NFR) yazımı |
| **Süreç modelleme** | As-is / to-be swimlane akışları, kök neden etiketleme, verimsizlik ve kopuş noktası tespiti, iyileştirme önerisi |
| **Agile dokümantasyon** | Epic kırılımı, Given/When/Then kabul kriterleriyle user story, bağımlılık ve öncelik yönetimi |
| **Test ve doğrulama** | UAT senaryoları (mutlu yol / alternatif / negatif), test veri seti kurgusu, gereksinim–story–test izlenebilirlik matrisi |
| **Veri analizi** | SQL sorgulama, Power BI ile görselleştirme ve raporlama |
